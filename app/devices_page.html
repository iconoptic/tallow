The panel starts the map itself. It runs on the root board when one is plugged into this machine by USB, and writes data/mesh/map.json. The other boards only need power. This page reads that file every 5 s.

With --mesh off, start it by hand: tools/mesh.sh daemon run <port> --out data/mesh/map.json, where <port> is the root board's USB serial port, listed by tools/mesh.sh ports.
